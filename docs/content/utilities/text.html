Make line endings more even and avoid single-word last lines (orphans) using .CIC-text-wrap-pretty for general text that is not centred and .CIC-text-wrap-balance for short, centre-aligned headings or lead copy.

Word break

Prevent long strings of text from breaking your components’ layout by using .CIC-text-break to set word-wrap: break-word and word-break: break-word. We use word-wrap instead of the more common overflow-wrap for wider browser support, and add the deprecated word-break: break-word to avoid issues with flex containers.

Class Properties
CIC-overflow-break overflow-wrap: break-word;
CIC-word-break-normal word-break: normal;
CIC-word-break-break-all word-break: break-all;
CIC-word-break-keep-all word-break: keep-all;
