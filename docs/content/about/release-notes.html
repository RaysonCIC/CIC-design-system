warning

Sass upgrade required

This release uses Sass 1.87+, which requires projects to upgrade to Sass 1.62 or above to avoid build failures. It also addresses a significant number of deprecation warnings that were appearing in previous builds.

This follows the official deprecation of @import and global function access (including colour functions like darken()) in Dart Sass 1.80.0, released October 2023.

More information: sass-lang.com: Import and global module changes
