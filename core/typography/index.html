Font

CIC Insurance uses Ubuntu font for all digital products and services to create a distinct but consistent look and feel. Ubuntu is the only font to be used for headings and body copy. It is a free font that is available from Google Fonts.

As Ubuntu is a custom font it's recommended to use Web Safe Font as a fallback when declaring your font stack. The preferred fallback font for the CIC Design System is Arial.

body {font-family: 'Ubuntu', Arial, sans-serif;}
